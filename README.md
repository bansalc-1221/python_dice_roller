# 🎲 Dice Roller

A Python-based command-line dice roller built to demonstrate randomization, user interaction, modular programming, and core programming fundamentals.

---

## 📌 Overview

Dice Roller is a simple terminal-based Python application that simulates rolling a six-sided die. The project focuses on implementing interactive gameplay while practicing essential Python concepts such as functions, loops, lists, conditional statements, and the `random` module.

At the end of each session, the application generates a game summary, including roll history and basic statistics.

---

## ✨ Features

- 🎲 Simulates a six-sided dice roll
- 🔄 Roll multiple times in a single session
- ✅ Input validation for user responses
- 📋 Stores complete roll history
- 📊 Displays game statistics
  - Total Rolls
  - Highest Roll
  - Lowest Roll
  - Average Roll
- 🧩 Modular code structure using Python functions

---

## 🛠️ Technologies Used

- Python 3
- Built-in `random` module
